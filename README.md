# Jersey4U — Football Jersey E-Commerce & Customizer

A full-stack football jersey e-commerce web platform built from scratch with:
- **Backend:** Java 17, Spring Boot 3, Spring Data JPA, Spring Security, JWT, MySQL
- **Frontend:** React.js (Vite), React Router, Axios
- **Payment:** Razorpay (Test Mode)

## Project Structure
- `backend/`: Spring Boot REST API
- `frontend/`: React Single Page Application (SPA)
